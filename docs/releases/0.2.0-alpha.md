# Falcon OSINT Framework 0.2.0-alpha

Released: 2026-11-13

This alpha closes the E12 milestone with a local-first assistant and expands the
offline knowledge base. It is still an alpha: interfaces and data contracts may
change before 1.0.

## Highlights

- **AI Assistant (E12).** Local retrieval over the SQLite catalog, Academy and
  Playbooks, deterministic offline briefings, note triage, prompt previews and an
  optional Ollama connection restricted to loopback hosts.
- **Explicit data boundary.** No model call happens without a per-query consent
  checkbox. Case notes stay in the page and are excluded unless the analyst opts
  in. There are no remote providers or API keys.
- **Academy expansion.** Four new lessons, three labs and a quiz covering claim
  triage, geolocation, corporate records and evidence archiving, with source
  links shown in the UI.
- **Catalog growth.** 31 new entries for environmental monitoring, archiving,
  data analysis, corporate registries, historical imagery, synthetic media and
  GNSS interference. The shipped database contains 140 tools.
- **Falcon favicon.** SVG icon linked from the app shell and the web manifest.

## Verification

- `npx vitest run`: 70 tests passing.
- `npm run build`: passing.
- `npm run db:validate`: all JSON files valid.
- Chrome smoke test: catalog, assistant panel, offline retrieval, note triage,
  prompt preview, consent gating and Academy sources verified with no page
  errors.

## Upgrade notes

- `database/falcon.db` was rebuilt from the JSON sources; no manual migration is
  required.
- Browser data under `falcon:*` keys is compatible with 0.1.0-alpha.
- The app still needs an HTTP server (`npm run dev` or `npm run preview`).

## Known limitations

- Ollama is not bundled. Model calls were unit-tested with a mocked transport,
  not against a live model in CI.
- The favicon is SVG-only; very old browsers may ignore it.
- The assistant retrieves by keywords, not embeddings; large catalog growth may
  require a vector index later.
